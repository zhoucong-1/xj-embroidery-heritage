# 绣缕山河·云展新疆 - 新疆非遗刺绣数字传承平台

## 项目简介

"绣缕山河·云展新疆"是一个致力于新疆非遗刺绣数字传承的平台，通过数字化技术展示新疆各民族刺绣的独特魅力，促进非遗文化的保护、传承和传播。

## 项目功能

### 前端功能
- **首页**：展示非遗项目、工艺特色和最新动态
- **非遗刺绣**：详细展示新疆各民族的刺绣项目
- **工艺教程**：提供刺绣工艺的详细教程
- **新闻动态**：发布与非遗刺绣相关的新闻和活动
- **关于我们**：介绍项目背景和团队信息
- **联系我们**：提供联系方式和留言功能

### 后端功能
- **非遗项目管理**：支持添加、修改、删除和查询非遗项目
- **新闻管理**：支持添加和查询新闻动态
- **数据存储**：使用内存数据库存储数据
- **API接口**：提供完整的RESTful API接口

## 技术栈

- **前端**：HTML5, CSS3, JavaScript
- **后端**：Node.js, Express
- **数据库**：sql.js (内存数据库)
- **其他**：CORS, Multer

## 快速开始

### 安装依赖

```bash
# 进入后端目录
cd backend

# 安装依赖
npm install
```

### 初始化数据

```bash
# 运行数据初始化脚本
node initData.js
```

### 启动服务器

```bash
# 启动后端服务器
npm start
```

服务器将运行在 `http://localhost:5181`

## API接口

### 非遗项目
- `GET /api/heritage` - 获取所有非遗项目
- `GET /api/heritage/:id` - 获取单个非遗项目
- `POST /api/heritage` - 添加新的非遗项目
- `PUT /api/heritage/:id` - 更新非遗项目
- `DELETE /api/heritage/:id` - 删除非遗项目

### 新闻
- `GET /api/news` - 获取所有新闻
- `POST /api/news` - 添加新闻
